# Art Loss Register

Research for issue #237 (catalog id `art_loss_register`). Checked against the Art Loss Register's own site on 2026-11-03.

**Step 1 answer: no API.** The Art Loss Register's FAQ describes only manual searches, started from its website or the "My Account" area, and mentions no API or automated search. Searches are paid: a single search is £85, €100 or $110, an urgent search £300, €350 or $400, and yearly bundles start at £700, €800 or $850 for up to 10 searches. Its database of over 700,000 items includes jewellery and watches. Watches go through its sister service, The Watch Register. Move this to Phase 2. Until an API exists, the Brain could record each search's result when staff upload the certificate.
