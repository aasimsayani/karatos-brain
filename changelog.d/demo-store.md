- Demo store (`@karatos/demo`): Example Street Jewelers, a made-up store whose data runs through six real connectors (Metals-API, POS exports, Plaid, QuickBooks, Twilio and WatchSearch) and the full retail brain. On every seed it produces 13 recommendations across seven departments: aged stock, reorders, a high return rate, a lapsed customer, missed calls, a watch dealers want, a gold price move, a cash deposit gap, overdue invoices, a Form 8300 and an AML review. It serves the instance API read-only, takes Accept and Dismiss as feedback up to a daily limit, and reseeds each midnight UTC so the dates stay current. Every other built connector is listed with the reason it isn't in the demo yet, and a test fails when one is missing from both. Image: `packages/demo/Dockerfile`. See `docs/demo.md`.
