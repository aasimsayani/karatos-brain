- `npm run prs:plan` prints the order to merge the open PRs in: ready PRs first, then the ones most PRs are stacked on, then the ones sharing the fewest hand-written files, with what each still waits on and what it unblocks. `scripts/sync-open-prs.sh` syncs in the same order, base PRs before the PRs stacked on them, moves PRs stacked on a merged branch onto its base, and takes PR numbers to sync only those.
