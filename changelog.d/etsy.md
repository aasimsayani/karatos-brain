- Etsy connector (`@karatos/connectors`): imports five years of an Etsy shop's orders, then every order changed since the last sync, with every listing in every state and each product's price and stock. Orders, sales and full refunds arrive as the same events eBay's do, with `marketplace: "etsy"`. The shop is connected with `transactions_r listings_r` only, and after every token refresh the connector asks Etsy which scopes the token has and stops if any could change data, or if the token belongs to another shop. No buyer names, emails, addresses or messages are kept. Changing stock or price and marking an order shipped are declared behind the write gate and turned down. Turn it on with `etsy` in `ENABLED_INTEGRATIONS` and the `ETSY_*` settings in `secrets/manifest.json`.
- Connector test kit: an Etsy Open API v3 mock built from Etsy's docs, with listing and receipt fixture builders.
