- Bank and credit card statements connector: now reads PDF statements as well as CSV exports, from any bank. Section headings say which way money moved, dates without a year take the statement's closing year, balance and total lines are skipped, and a dated line the layout can't read is dead-lettered with its page and line. A PDF transaction gets the same key as its CSV row, so a transaction in both is stored once. A client's own layout goes in their profile under `pdf`. PDFs over 20 MB or 300 pages, password-protected and unreadable ones stop with the file named. Text lines over 500 characters are never run through the layout patterns, so a crafted PDF can't stall the sync
- Connector test kit: `syntheticPdf` and `statementPage` write small valid PDFs from synthetic text inside a test, so PDF fixtures never need to be checked in
- Instance image: leaves out optional native packages (pdf.js's canvas), which nothing in the instance uses
