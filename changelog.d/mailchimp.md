- Mailchimp connector (`@karatos/connectors`): imports every audience and subscriber, and five years of sent campaigns with their reports (sends, bounces, opens, clicks, orders, revenue, unsubscribes), then reads changed members and recent campaigns on every sync. It uses the same event types as Klaviyo, and each subscriber becomes the keyed reference custom forms makes for the same email address. A Mailchimp key can't be limited to reading, so the client sends its five listed GET reads only, and each read names the fields it wants so names, phone numbers, addresses and merge fields never leave Mailchimp. Mailchimp's member id (an MD5 of the address) is never kept. `verifyMailchimpWebhook` checks the secret in the webhook URL, since Mailchimp doesn't sign deliveries. Adding a contact is declared behind the write gate. Turn it on with `mailchimp` in `ENABLED_INTEGRATIONS`, `MAILCHIMP_API_KEY` and `CUSTOMER_REF_KEY`.
- Connector test kit: a Mailchimp mock built from its docs, with fixture builders for audiences, members, campaigns and reports.
- Nightly sandbox run: a Mailchimp check, which runs once `SANDBOX_MAILCHIMP_API_KEY` is set.
