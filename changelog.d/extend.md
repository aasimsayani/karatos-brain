- Added the Extend product protection connector (read-only): every product protection contract Extend holds for the store, as `warranty.contract_updated` with its status, plan, term, coverage, price and the product and order it covers, and every order, as `order.updated` with its status and totals. Later syncs keep what Extend updated since the last pass. An API Integration's client ID and secret are traded for a token sent in `X-Extend-Access-Token`; Extend has no read-only scope, so the client only sends GETs to the two searches after the token exchange. No customer names, emails, phones or addresses are kept. Extend's demo environment is a setting. Cancelling an order is declared behind the write gate and turned down.
- Connector test kit: an Extend mock built from Extend's API reference, with contract and order fixture builders.
