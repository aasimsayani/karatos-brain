- TikTok Ads connector (`@karatos/connectors`): imports two years of daily TikTok ad spend, impressions, reach, clicks, purchases and purchase value for every campaign in one advertiser, then reads the last four weeks again on every sync, as TikTok keeps attributing purchases to past views and clicks. It gives the same `ads.campaign_reported` event as Google Ads and Meta Ads. It connects with an advertiser token from an app made with read scopes only, and its only API request is the report read for the configured advertiser, built from one fixed report. Pausing and resuming a campaign are declared behind the write gate, turned off, each needing approval. Turn it on with `tiktok_ads` in `ENABLED_INTEGRATIONS`, `TIKTOK_ADS_ACCESS_TOKEN` and `TIKTOK_ADS_ADVERTISER_ID`.
- Connector test kit: a TikTok API for Business report mock built from its docs, with a fixture builder for campaign rows.
- Nightly sandbox run: a TikTok Ads check against a sandbox advertiser, which runs once its two `SANDBOX_TIKTOK_ADS_*` secrets are set.
