- Monday.com connector (`@karatos/connectors`): imports five years of items from every board the token can see, such as custom orders, repairs and production jobs, with their boards, groups and safe column values, and who commented when, then reads changes with monday.com's last-updated filter and the boards' activity logs for deleted and archived items. Pinned to API version 2026-07. The client sends only its own named read queries with variables it checked, so a mutation can never be sent; a monday app token listed with any write scope is refused, and a personal token, which can't be limited, is guarded by the same allowlist. Text, notes, emails, phone numbers, addresses, files, links, item names and comment words aren't kept unless the owner allows a column. Complexity and minute limits are waited out; the daily limit stops the sync until the next run; expired items cursors restart the board. `verifyMondayWebhook` checks the webhook JWT (HS256, Signing Secret, expiry) and `mondayWebhookChallenge` answers the creation challenge. The scheduled sync runs it when `monday` is in `ENABLED_INTEGRATIONS`.
- Connector test kit: a monday.com mock built from its docs, which answers only the connector's read queries and refuses mutations, with fixture builders for boards, items, updates and activity logs.
- Nightly sandbox run: a monday.com check, which runs once the `SANDBOX_MONDAY_API_TOKEN` secret is set.
