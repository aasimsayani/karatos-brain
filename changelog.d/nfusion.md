- Added the nFusion Solutions metals feed connector (read-only): gold, silver, platinum and palladium spot prices from nFusion's Market Data API, in US dollars per troy ounce, as the same `metal.price_updated` events Metals-API gives. The historical import reads five years of daily closes, 90 days a request, from a checkpoint it can resume; each incremental sync reads the closes since the last day it kept, then the latest spot summary. Requests are spaced over a second apart, nFusion's rate limit (HTTP 403 with substatus 502) is waited out and retried, and the token, which travels in the query string, never appears in an error or log. Nothing can be written through the API.
- Connector test kit: an nFusion Market Data API mock built from its OpenAPI spec, with spot summary and daily interval fixture builders.
