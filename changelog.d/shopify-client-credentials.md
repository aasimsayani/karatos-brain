- Shopify connector signs in with a Dev Dashboard app's client ID and secret (`SHOPIFY_CLIENT_ID`, `SHOPIFY_CLIENT_SECRET`), since Shopify stopped letting merchants create custom apps in the store admin on 2026-01-01. It requests the 24-hour Admin API token itself and renews it 5 minutes early or when Shopify revokes it. `SHOPIFY_ADMIN_ACCESS_TOKEN` still works for stores with an older admin-made app. Catalog entries can list several ways to sign in (`signIn`), and an integration counts as configured when any one is complete. The nightly sandbox check now uses `SANDBOX_SHOPIFY_CLIENT_ID` and `SANDBOX_SHOPIFY_CLIENT_SECRET`
