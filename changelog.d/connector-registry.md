- Connector registry: each connector now keeps everything about itself in its own files, so connector PRs no longer conflict with each other. Its catalog fields are in `packages/core/src/catalog/<id>.ts`, its factory in `packages/server/src/connectors/<id>.ts`, its sandbox check in `scripts/sandbox-checks/<id>.ts`, its settings in `secrets/manifest/<id>.json` and its docs in `docs/integrations/<id>.md`; a mock module declares what it covers and the doc pages it watches. `npm run registry:write` generates every shared list from them: the export lists, `allDocMocks()`, the runner's factories, the sandbox checks, `secrets/manifest.json`, the `SANDBOX_*` lines in the nightly workflow, and the catalog tables, mock list and connector sections in `docs/integrations.md`. `npm run registry:check` runs in CI and fails when a generated file is stale. A setting several connectors need is listed once in `secrets/manifest/shared.json` and named in each connector's `uses`. Tests take their counts and lists from the catalog. See CONTRIBUTING.md.
- The catalog tables in `docs/integrations.md` now show each entry's catalog note, so they match the website and the Console.
- `scripts/sync-open-prs.sh` settles a conflict in a generated connector list by running `npm run registry:write`, and checks `registry:check` before pushing.
