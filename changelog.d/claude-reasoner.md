- The Claude reasoner: with `CLAUDE_REASONER=on` and `ANTHROPIC_API_KEY` set (off by default), each reasoning run sends Claude Opus 5.5 a bounded, redacted summary of the recent signals and the rules' recommendations, by reference only (no recommendation text, customer names, emails or phone numbers), and keeps the findings it returns in a JSON schema only when every reference each one cites is in the summary. Findings are recommendations with rule `claude` and provenance down to the signals, events and rule recommendations they cite; confidence is capped at 0.5 and below the lowest rule unless the finding cites a rule recommendation, and then at that recommendation's. The feedback loop's cooldown and ranking apply to them like any rule, never lifting one past its cap. `CLAUDE_REASONER_MAX_TOKENS` (default 40000) caps tokens a run and `CLAUDE_REASONER_TIMEOUT_SECONDS` (default 90) the wait; a time-out, error, refusal or malformed answer leaves the rules' run as it was. Each run records the model, prompt version, token usage and outcome in `reasoning_runs.model_reasoning` (migration `20261128000001_reasoning_run_model.sql`). The server depends on `@anthropic-ai/sdk`. See docs/claude-reasoner.md.
