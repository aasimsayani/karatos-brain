- Changelog fragments: each PR adds `changelog.d/<branch>.md` instead of editing `CHANGELOG.md`, so open PRs no longer conflict on it. CI checks every PR has a valid fragment and leaves `CHANGELOG.md` alone (`npm run changelog:check`); `npm run changelog:collect` folds the fragments in at release and tidies the Unreleased list. `scripts/sync-open-prs.sh` brings main into every open PR after a merge and moves stray changelog lines into fragments
