- Gem Logic connector (`@karatos/connectors`): reads every product on each of a business's Gem Logic sales channels, and reads them all again on each later sync, since Gem Logic can't list what changed. Each becomes a `product.updated` event with its SKU, status, channel, image count, weight and size; image links aren't kept. Gem Logic keys can't be limited, so the client sends only GET requests to the sales channels and their products; nothing is written back. Turn it on with `gem_logic` in `ENABLED_INTEGRATIONS`, `GEM_LOGIC_API_KEY` and `GEM_LOGIC_INSTANCE`.
- Connector test kit: a Gem Logic API mock built from its docs, with a product fixture builder.
