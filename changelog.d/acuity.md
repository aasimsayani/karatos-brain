- Added the Acuity Scheduling connector (read-only): two years of appointments and the 90 days ahead, scheduled and canceled, as `appointment.booked`, `appointment.canceled` and `appointment.no_show` in the Calendly shapes, with each one's type, calendar, time, length, price and amount paid; later syncs keep 60 days back to 90 days ahead current. Acuity has no paging, so it reads in date windows of at most a month, halving any window that fills a request down to a day, and dead-letters a marker for a day that still does. The API key can't be limited to reading, so the client only sends GET requests. Names, emails, phone numbers, notes and intake form answers are never kept; the email and phone only make keyed customer references. Cancelling an appointment is declared behind the write gate and turned down.
- Connector test kit: an Acuity Scheduling API mock built from Acuity's docs, with appointment, appointment type and calendar fixture builders.
