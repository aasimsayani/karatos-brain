- Outlook and IMAP mail now carry `customerRefs` for the other side of each message (the sender of a received one, the To and Cc of a sent one) when the instance has a `CUSTOMER_REF_KEY`, made by Gmail's own helper, so the same address gives the same reference from every mailbox, form and marketing system. An email reply from either mailbox now answers a customer's text, WhatsApp message or email in `clienteling.awaiting-reply`, and their senders link with their orders. The mailbox's own address (`MICROSOFT_OUTLOOK_MAILBOX`, or `IMAP_USERNAME` when it is an address) is never taken for a customer. The server factories hand the key over when it is set; raw addresses are still only hashed.
