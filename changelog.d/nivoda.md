- Nivoda connector (`@karatos/connectors`): reads the diamonds a saved Nivoda search finds (`NIVODA_QUERY`) through the business's own buyer account, and records each diamond that is new or changed as `diamond_listing.listed`, with grades, measurements and its price, and each one that leaves the search as `diamond_listing.delisted`. Requests are spaced 30 seconds apart as Nivoda asks, the 6-hour token is renewed before it runs out, and the password is sent only to Nivoda's fixed staging and production addresses. A search over 1,000 diamonds (`NIVODA_MAX_STONES`) stops the sync, an empty one never delists, and a search that changes while it is read delists nothing that sync. Media links aren't stored. Turn it on with `nivoda` in `ENABLED_INTEGRATIONS` and the `NIVODA_*` settings in `secrets/manifest.json`.
- Connector test kit: a Nivoda mock built from Nivoda's API help pages, with a synthetic diamond builder and token expiry.
