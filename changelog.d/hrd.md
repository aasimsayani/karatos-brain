- HRD Antwerp connector (`@karatos/connectors`): looks up the HRD report behind each report number on the business's list once through the public MyHRD API, with shape, carat weight, color, clarity, cut, polish, symmetry, fluorescence and proportions for a diamond, and type, metal, diamond count and carat weight for a jewel. Each night, while HRD answers it, it checks which reports are still valid: a reissued report is looked up again and one HRD no longer lists is flagged once as `grading.report_unavailable`, like a number HRD has no report for. The client sends two read requests only, to HRD's own host, keeps inside HRD's request limits (`HRD_MAX_LOOKUPS_PER_SYNC`, 50 by default), and reads XML with a strict reader that expands nothing. Turn it on with `hrd` in `ENABLED_INTEGRATIONS` and the `HRD_*` settings in `secrets/manifest.json`.
- Connector test kit: an HRD mock built from its API guide, with diamond and jewel report builders.
