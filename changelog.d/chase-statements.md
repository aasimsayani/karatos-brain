- Chase connector: imports Chase business checking, savings and credit card activity from CSV downloads, PDF statements or both, as `CHASE_IMPORT_MODE` picks, from one folder per account under `CHASE_MANUAL_IMPORT_DIR`. Chase's layouts are built in, including checks paid by number, spelled-out statement periods and card opening/closing dates. A transaction in both a CSV and a PDF is stored once. The scheduled sync runs it when `chase` is in `ENABLED_INTEGRATIONS`.
- Bank statements: `BANK_STATEMENTS_PROFILES` now also takes a built-in profile name (`generic`, `chase_checking`, `chase_card`), alone or per folder in the JSON file. A PDF layout can list several transaction patterns, tried in order.
