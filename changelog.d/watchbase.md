- Added the WatchBase Data Feed connector (read-only): reference specs for every watch of the brands a store lists, with each watch's caliber, case, dial, water resistance and release year, as `watch_reference.updated`. The first syncs read each brand in full; later ones read only the watches WatchBase added or changed (`updated-since`). The historical import reads nothing, since specs have no history. Each watch read costs US$0.25 in DataFeed credits, so a sync reads at most `WATCHBASE_MAX_WATCHES` (200 unless set) and the next one goes on from there. The key travels as the `key` query parameter and is never put in an error or log; no descriptions or images are kept, and nothing is declared to write.
- Connector test kit: a WatchBase Data Feed mock built from WatchBase's datafeed manual, with brand and watch fixture builders.
- The catalog's `watchbase_datafeed` entry is now a self-serve paid account, not partner only.
