- Inventory and POS connector (`@karatos/connectors`): reads CSV exports of item lists, stock counts, customer lists and sales lines from any POS out of a folder (`POS_IMPORT_DIR`), through a column-mapping profile (`POS_MAPPING_PROFILE`: the built-in generic profile, or a client's own JSON kept in their instance repo). Sale lines become receipts in the sales department's shape and negative lines become returns; items become receipts, customers become clienteling profiles without contact details, and unreadable values are dead-lettered with the file and row kept. Each sync reads only new or changed files and resumes mid-file after a crash. Read-only, five years of history, no writes declared
- Shared file import code for the POS and bank statement connectors: an RFC 4180 CSV reader and money, date and yes/no parsers that return null rather than guess. The inventory department accepts a new `inventory.counted` event, and the connector test kit's `testPipeline` and `checkConnectorSync` take department payload schemas so a connector's dead letters can be checked against them
