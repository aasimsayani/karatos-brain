- Google Ads connector (`@karatos/connectors`): imports two years of daily spend, impressions, clicks, conversions and conversion value for every campaign in one account, with each campaign's status, channel and daily budget, then reads the last two weeks again on every sync, as Google keeps attributing conversions to past clicks. Google Ads has one scope, which can change campaigns, so the client keeps the connection read-only: its only API request is `googleAds:search` for the configured account, built from one fixed report, and it never calls mutate. Pausing a campaign and changing its budget are declared behind the write gate, turned off, each needing approval. Turn it on with `google_ads` in `ENABLED_INTEGRATIONS`, `GOOGLE_ADS_REFRESH_TOKEN`, `GOOGLE_ADS_DEVELOPER_TOKEN`, `GOOGLE_ADS_CUSTOMER_ID` (and `GOOGLE_ADS_LOGIN_CUSTOMER_ID` through a manager account) and the shared Google OAuth client.
- Connector test kit: a Google Ads API mock built from its docs, with a fixture builder for campaign rows.
- Nightly sandbox run: a Google Ads check against a test account, which runs once its six `SANDBOX_GOOGLE_ADS_*` secrets are set.
