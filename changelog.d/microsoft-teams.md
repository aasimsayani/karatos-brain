- Microsoft Teams connector (`@karatos/connectors`): reads one team's channel messages and replies through Microsoft Graph: five years back, then each sync reads only the threads that changed since the last. Messages become `communication.message_logged` (or `communication.message_deleted`), with the channel, thread, times, importance and counts of attachments, mentions and reactions, and the poster as a private `teams_user:` reference under `CORRESPONDENT_HASH_KEY`. Message text, subjects, attachments, channel names and display names are never kept. The app holds only the resource-specific consent permissions ChannelMessage.Read.Group and ChannelSettings.Read.Group, granted when the one team installs it, and the client stops if its token carries any permission that isn't a read one; posting alerts and daily summaries are declared and turned off. Turn it on with `microsoft_teams` in `ENABLED_INTEGRATIONS`, `MICROSOFT_TENANT_ID`, `MICROSOFT_TEAMS_CLIENT_ID`, `MICROSOFT_TEAMS_CLIENT_SECRET`, `MICROSOFT_TEAMS_TEAM_ID` and `CORRESPONDENT_HASH_KEY`.
- Connector test kit: a Microsoft Graph Teams channel and message mock built from Microsoft's reference, with fixture builders for channels, messages and replies. The synthetic-data check no longer takes a Teams thread id (`19:…@thread.tacv2`) for an email address.
