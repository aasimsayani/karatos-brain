- Added the Instagram DMs, Facebook Messenger and WhatsApp Business connector (read-only): the store's Messenger and Instagram conversations from the Graph API v26.0 with a Page access token, and WhatsApp messages and delivery statuses from signed webhooks, all as `communication.message_logged` in the Quo shape. The historical import walks five years of conversations and reads each one's 20 most recent messages, the most Graph lets be read; later syncs read conversations updated since the last pass. A sync sends at most 2,100 requests. Webhooks check `X-Hub-Signature-256` in constant time, answer Meta's `hub.challenge` only for the right verify token, and dedupe replays. No message text, attachments, names, emails, usernames or numbers are kept; customers become keyed references. Meta has no read-only messaging permission, so the client only sends GET requests. Replying and marking read are declared behind the write gate and turned down. The catalog's `meta` entry is no longer deferred.
- Connector test kit: a Graph API mock for Page conversations, conversations and messages built from Meta's docs, with Messenger, Instagram and WhatsApp webhook fixture builders.
