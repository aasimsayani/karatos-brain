- Sync verification (`POST /v1/verify`, `npm run verify-sync`): for a period of store days in `STORE_TIME_ZONE`, compares what an instance has synced with the source system's own totals. It checks Shopify and Square paid sales (count and gross before refunds, as the daily brief counts them), Stripe captured charges (count and gross) and Klaviyo profiles created in the period. Each metric reports match, mismatch or unavailable, the source and synced totals, the difference and up to 20 ids missing from either side. Counts must agree exactly, record by record, and money to the cent unless the request sets a tolerance of up to a dollar. Each source is read with the read calls and scopes its connector already syncs with, with no new scope and no writes. Klaviyo is asked for profile times only. Instance key only (the support key gets 403), one run at a time (429 while one runs), and the output never holds names, emails, phone numbers, vendor error messages or payloads. See [verifying synced numbers](docs/verify-sync.md).
- Connectors (`@karatos/core`, `@karatos/connectors`): an optional `verify(period)` on `Connector`, built for Shopify, Square, Stripe and Klaviyo. The Klaviyo client also allows asking for profiles' `created,updated` fields alone.
