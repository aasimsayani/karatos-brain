- Formlabs connector (`@karatos/connectors`): imports a year of print runs from a workshop's Formlabs printers, then the runs made in the last few days on each later sync. Each becomes a `manufacturing.print_updated` event with its printer, status, whether it succeeded, resin, volume, layers and times. A print's name, who sent it, notes, part names and photos aren't kept. Formlabs tokens can't be limited, so the client asks only for a token and lists print runs; nothing is written back. Turn it on with `formlabs` in `ENABLED_INTEGRATIONS`, `FORMLABS_CLIENT_ID` and `FORMLABS_CLIENT_SECRET`.
- Connector test kit: a Formlabs Web API mock built from its published reference, with a print run fixture builder.
