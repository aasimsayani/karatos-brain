- TikTok connector (`@karatos/connectors`): imports every public video the store posted in the last two years, with its title, link, length and views, likes, comments and shares, reads the last 90 days of videos again on each sync, and records the account's followers and total likes each day. It connects with `user.info.basic`, `user.info.stats` and `video.list` only and stops if the token holds anything more, its only API requests are the profile read and the video list, and it keeps the newest refresh token sealed in the instance's database. Posting a product video is declared behind the write gate, turned off, needing approval. Turn it on with `tiktok` in `ENABLED_INTEGRATIONS`, `TIKTOK_CLIENT_KEY`, `TIKTOK_CLIENT_SECRET` and `TIKTOK_REFRESH_TOKEN`.
- Connector test kit: a TikTok Display API v2 mock built from TikTok for Developers' docs, with a fixture builder for videos.
- Nightly sandbox run: a TikTok check against a sandbox test account, which runs once its three `SANDBOX_TIKTOK_*` secrets are set.
